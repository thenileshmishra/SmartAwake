# SmartAwake

A Chrome extension that prevents your system or display from going to sleep. Perfect for presentations, long-running tasks, or when you need to keep your screen active.

## Features

- Keep your display awake while allowing the system to sleep
- Keep both your display and system awake
- Easy one-click activation and deactivation
- Simple and intuitive user interface

## Installation

1. Download or clone this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" in the top right corner
4. Click "Load unpacked" and select the SmartAwake directory

## Usage

1. Click the SmartAwake extension icon in your Chrome toolbar
2. Choose your preferred mode:
   - "Keep Display Awake" - Prevents only the display from sleeping
   - "Keep System Awake" - Prevents both the display and system from sleeping
3. Click "Release" when you want to return to normal power settings

## Permissions

SmartAwake requires the following permissions:
- `power` - To manage system power settings
- `storage` - To save user preferences
- `tabs` - For extension functionality
- `scripting` - For background operations
